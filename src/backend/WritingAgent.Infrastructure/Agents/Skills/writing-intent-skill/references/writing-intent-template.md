# 写作意图标准模板

一个合格的写作意图应包含以下字段：

## 1. 原始想法

保留用户最初的模糊输入，不做过度改写。

## 2. 写作主题

用一句话说明这篇内容要讨论什么。

## 3. 目标读者

明确写给谁看，例如：一线开发者、技术管理者、创业者、产品经理、普通用户。

## 4. 写作目的

明确这篇内容希望帮助读者达成什么结果或决策。

## 5. 发布平台

明确内容主要发布在哪个平台，例如：公众号、博客、知乎、即刻、内部文档。

## 6. 核心观点

明确作者想表达的判断，而不只是一个中性主题。

例如：

- 不够好：AI Coding
- 更好：AI Coding 的重点不是替代程序员，而是改变工程协作方式。

## 7. 内容边界

明确这篇文章不展开什么，避免主题无限扩大。

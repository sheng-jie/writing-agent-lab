# 贯通六阶段并清理旧推进旁路

Status: ready-for-agent
Blocked by: 02, 03, 04

## What to build

让作者可以从捕捉想法一路推进到文章配图，六个阶段都只通过显式候选阶段产物和“下一步”确认接受；清除所有通过任意非空草稿、卡片确认或直接字段更新自动完成阶段的旧路径。

## Acceptance criteria

- [ ] 六个正式阶段统一使用候选阶段产物存在性和 Agent 空闲状态判断是否可接受，不再通过任意非空草稿或更新时间推断。
- [ ] 所有工作区专属生成动作和 Agent 工具均不能直接写入已接受产物、标记 `accepted` 或开启下一阶段。
- [ ] 六阶段参数化测试验证：生成候选后仍为 `in-progress`，取消接受无副作用，确认接受后原子推进且流程进度仅按 accepted 计算。
- [ ] 完整工作流验收验证阶段顺序、下游只读取已接受产物、最后阶段接受后可保存文章，以及 accepted 后只能整条重置。
- [ ] 清除或收紧与新规则冲突的旧推进、上游修改和局部重置旁路，不引入三种阶段状态以外的新状态。
- [ ] 捕捉想法浏览器验收验证：生成卡片后可继续对话修改且内容不被清空，下一步确认后才进入选题生成。
- [ ] 前端相关测试、lint 和生产构建通过；桌面与窄屏下接受弹窗、摘要和操作栏无内容遮挡或意外横向滚动。

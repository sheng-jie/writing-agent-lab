# 跑通捕捉想法的候选阶段产物接受

Status: ready-for-agent
Blocked by: None

## What to build

让作者确认生成结构化写作意图卡片后仍停留在捕捉想法阶段并可继续通过右侧协作区修正；只有候选阶段产物已经生成、Agent 空闲且作者点击“下一步”并在弹窗中确认后，系统才接受当前写作意图并进入选题生成。

## Acceptance criteria

- [ ] 确认生成结构化写作意图卡片时，系统建立候选阶段产物和当前草稿，但阶段保持 `in-progress`，选题生成保持 `pending`，流程进度不增加。
- [ ] 左侧结构化写作意图卡片只读展示当前草稿，作者可以继续通过右侧协作区修正内容，修正不会清空现有字段、候选阶段产物或 Agent 对话。
- [ ] Agent 再次生成结构化写作意图时按字段合并；未提供字段保留原值。
- [ ] 只有候选阶段产物存在且 Agent 空闲时，“下一步”可用；任意非空零散草稿不能开放推进。
- [ ] 点击“下一步”只打开确认弹窗，不立即修改阶段状态、产物、修订号或当前工作区。
- [ ] 弹窗说明确认后当前阶段将锁定并进入选题生成，并展示写作主题、目标读者和核心观点摘要。
- [ ] 取消弹窗时所有工作流状态与产物保持不变；确认时原子地固定当前草稿为已接受产物、递增修订号、将捕捉想法设为 `accepted`、开启并进入选题生成。
- [ ] 工作流状态控制器测试覆盖卡片生成、后续修正、Agent 运行门禁、取消和确认的用户可观察结果。

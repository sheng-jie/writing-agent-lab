# 跑通初稿、润色稿与配图稿的候选阶段产物接受

Status: ready-for-agent
Blocked by: 01

## What to build

让作者在撰写初稿、润色改写和文章配图阶段先生成完整候选产物并持续修正，分别确认后再推进；接受最后的配图稿后仍可按既有流程保存文章。

## Acceptance criteria

- [ ] 撰写初稿工作区提供明确的完整候选初稿生成入口；零散正文更新不自动开放“下一步”或接受阶段。
- [ ] 候选初稿可继续修正，接受弹窗展示正文关键摘要；取消无副作用，确认后进入润色改写。
- [ ] 润色改写工作区提供明确的完整候选润色稿生成入口；候选润色稿可继续修正，确认接受后进入文章配图。
- [ ] 文章配图工作区提供明确的完整候选配图稿生成入口；候选配图稿可继续检查和修正，不因生成完成而自动接受。
- [ ] 三个阶段的“下一步”均只在候选阶段产物存在且 Agent 空闲时可用，并展示与本阶段产物匹配的简短摘要。
- [ ] 文章配图阶段确认接受后固定配图稿并保持文章可保存；取消时不改变阶段状态、产物或保存能力。
- [ ] 工作流状态控制器与必要的组合测试验证三个阶段遵循同一候选、修正、确认接受合同。

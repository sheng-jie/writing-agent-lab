# 跑通选题生成与大纲规划的候选阶段产物接受

Status: ready-for-agent
Blocked by: 01

## What to build

让作者在选题生成和大纲规划中先获得明确的完整候选阶段产物，继续修正后，再分别通过“下一步”确认接受确定选题和写作大纲。

## Acceptance criteria

- [ ] 选题生成工作区提供明确的完整候选产物生成入口；零散选题字段更新只修改草稿，不自动开放“下一步”。
- [ ] 候选选题生成后阶段保持 `in-progress`，作者可以继续通过当前协作区修正，修正不自动接受或清空内容。
- [ ] 选题生成的接受弹窗展示该阶段的关键摘要；取消无副作用，确认后固定当前确定选题并进入大纲规划。
- [ ] 大纲规划工作区提供明确的完整候选产物生成入口；零散大纲字段更新只修改草稿，不自动开放“下一步”。
- [ ] 候选写作大纲生成后阶段保持 `in-progress`，作者可以继续修正，修正不自动接受或清空内容。
- [ ] 大纲规划的接受弹窗展示文章主线、章节安排或素材缺口等关键摘要；取消无副作用，确认后固定当前写作大纲并进入撰写初稿。
- [ ] 两个工作区均在 Agent 运行时禁止接受，在 Agent 空闲后恢复“下一步”。
- [ ] 工作流状态控制器与必要的组合测试验证两个阶段遵循同一候选、修正、确认接受合同。

# accepted 后整条重置

Status: ready-for-agent
Blocked by: 01

## What to build

让作者在任一阶段已接受后无法直接修改阶段产物；需要返工时只能通过明确确认的重置操作，清空整个写作工作流并回到首次输入前。

## Acceptance criteria

- [ ] 阶段进入 `accepted` 后，项目字段更新、阶段草稿更新和 Agent 工具更新均不能修改该阶段产物。
- [ ] 任一 accepted 阶段执行重置时都先展示确认弹窗，不因下游尚无产物而跳过确认。
- [ ] 弹窗明确说明将清空整个写作工作流的全部阶段状态与产物、当前项目内容和 Agent 对话。
- [ ] 取消重置时工作流、项目内容、文章保存标记、当前工作区和 Agent 对话均保持不变。
- [ ] 确认重置后所有阶段恢复初始状态，当前项目阶段产物与文章保存标记清空，当前工作区回到捕捉想法，Agent 对话清空。
- [ ] 重置后作者看到首次输入前的捕捉想法工作区，不再看到旧结构化写作意图卡片或旧会话。
- [ ] 工作流状态控制器测试覆盖 accepted 写保护、重置取消和整条重置的可观察结果。
